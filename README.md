# 高等学校化学「電池」学習アプリ

## 電池の原理と反応式マスター

高等学校化学の「電池」を、電池内部で起こる酸化還元反応と電子・イオンの移動に着目して学習するためのWebアプリです。

電池の種類を切り替えながら、放電・充電時の状態をアニメーションで確認し、その後に反応式や電極のはたらきをクイズ形式で確認できます。

## 対象

- 高等学校「化学」
- 電池・電気化学の学習
- 酸化・還元と電極の関係の確認
- 電子・イオンの移動の理解
- 一次電池・二次電池・燃料電池の比較

## 主な機能

### 1. 電池の原理をアニメーションで学ぶ

「原理を学ぶ（アニメーション）」モードでは、電池の種類と放電・充電の状態を切り替えながら、電池内部の変化を視覚的に確認できます。

電子（e⁻）は外部回路を移動する粒子として、イオンや分子は電解質中を移動する粒子としてアニメーション表示されます。

### 2. 5種類の電池を比較

以下の電池を選択できます。

- ダニエル電池（一次電池）
- 鉛蓄電池（二次電池）
- リチウムイオン電池（二次電池）
- 燃料電池（リン酸型）（一次電池）
- 燃料電池（アルカリ型）（一次電池）

それぞれについて、電極、電解質、電子やイオンの移動、反応の進行を図示します。

### 3. 放電と充電を比較

鉛蓄電池やリチウムイオン電池では、放電と充電による反応・粒子移動の向きの違いをアニメーションで確認できます。

一次電池や燃料電池については、それぞれの性質に応じた状態を表示します。

### 4. 起電力の目安を表示

選択した電池について、起電力の目安を表示します。電池の種類を切り替えることで、電池ごとの特徴を比較できます。

### 5. 反応式クイズ

「反応式クイズ」モードでは、電池に関する4択問題に取り組みます。

問題には、次のような内容が含まれています。

- ダニエル電池の負極・正極で起こる反応
- 素焼き板の役割
- イオン化傾向と起電力の関係
- 鉛蓄電池の正極・負極の活物質
- 鉛蓄電池の放電・充電時の半反応式
- 鉛蓄電池の電解液の変化
- 充電時の外部電源との接続
- リチウムイオン電池の電極反応
- 放電時のLi⁺の移動
- 燃料電池（アルカリ型・リン酸型）の電極反応
- 燃料電池の全体反応式
- 電子が流れ出す極・入り込む極と、酸化・還元の関係

収録された問題群から毎回5問をランダムに出題します。

### 6. 解説・スコア機能

解答後には、その問題の正解と反応の理由を確認できます。

正解すると基本点に加えて解答時間に応じたタイムボーナスが加算され、5問終了後に合計スコア、正答数、総解答時間を表示します。最高スコアも保持されます。

## 学習の流れ

1. 「原理を学ぶ（アニメーション）」で電池の種類を選択する
2. 電子・イオンなどの移動を観察する
3. 放電・充電による変化を比較する
4. 「反応式クイズ」に挑戦する
5. 解説で反応の理由を確認する
